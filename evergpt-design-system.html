EverGPT

Foundever's internal assistant. White, navy and one indigo. Values sampled from the product screens.

Overview

EverGPT is Foundever's internal assistant: a quiet, white workspace where the only colour is a single indigo action and a lavender user bubble. Build every new surface — the Library included — so it reads as the same product as the chat.

Principles

  • White first, one indigo. Pages are surface with a surface-sidebar rail. brand appears once per view on the commit action (Publish to Web, voice). Everything else is greys and navy.
  • Navy, not black. Content text is ink (#0a0a30). Chrome text steps down: ink-secondary → ink-muted → ink-footnote.
  • Hairlines, not boxes. Structure is 1px border / border-soft. The composer is the only shadowed object (shadow-composer).
  • Small, calm type. 14px UI, 15px chat, 12px meta. The display face only for the greeting, page titles and answer headings.
  • One asset, one look. An asset is the same card in chat (AssetCard), in the panel header and in the Library (LibraryRow).

Content

  • Sentence case everywhere: "New chat", "Publish to Web", "Design system updates". Section labels are sentence case, not caps.
  • The assistant speaks as "I" ("I can:"); the user is addressed directly ("How can I help you today?").
  • State status in plain words beside the badge: "Not published", "Published · 2 days ago", "Shared by Ana Petrović".
  • No emoji in product chrome. (Generated pages may use them; the app does not.)

Colour

  • Canvas surface; rail surface-sidebar; header and panel rules border.
  • User bubble brand-soft; selected nav row brand-tint + brand-ink.
  • Neutral controls: model selector surface-muted; composer chips and round + surface-chip; asset tiles surface-tile.
  • Status colours are Library additions (status-* / on-status-*); Draft stays the captured neutral.
  • brand-line and border-control are decorative strengths from the source and fail 3:1 — never use them alone to carry meaning.

Type

  • ui (Inter) for chrome: sidebar, cards, badges, buttons, tables.
  • chat (Noto Sans) for conversation: bubbles, answers, composer, footnote.
  • display for greeting, title, answer-heading. The captured face is a geometric sans that could not be identified; Figtree stands in — swap to the official Foundever face when supplied.

Layout

  • Three panes: rail sidebar-width · chat (column max composer-width, centred) · optional artifact panel (≈45% width, 1px border left rule).
  • Headers are header-height with a bottom border rule.
  • Spacing steps space-1…space-8; 24px between chat turns; 16px card padding.
  • Radii grow with size: badge radius-xs → chip radius-sm → button/tile radius-md → card radius-lg → bubble radius-xl → composer radius-2xl.

Iconography

  • Outline icons, 18px (icon), 1.5px stroke, round caps, coloured by text. The screens match Tabler Icons; the previews redraw close equivalents — use Tabler (outline) in production.
  • Asset type icons: globe = webpage, monitor = presentation, file = report.

Library direction

How the Library applies this system. It is a page in the same shell — sidebar left, content right, no artifact panel until an asset is opened.

Entry

  • Add Library to the sidebar under Tools, after GPTs. Active state brand-tint / brand-ink.
  • Every in-chat AssetCard's ⋮ gets "Show in Library"; the panel header gets the same.

Page

  • Header header-height with title "Library" left, search (LibraryToolbar) right.
  • Filter pills below: All · Created by me · Shared with me | Drafts · Published · type.
  • List of LibraryRow, columns Name · Status · Updated · Access · ⋮. Default sort: last updated.
  • Each row's provenance line links back to its source chat — the asset never loses where it came from.

Opening an asset

  • Clicking a row opens the existing artifact panel (PanelHeader + preview) over the right of the Library, exactly as in chat; primary action follows status: Draft → "Publish to Web", Published → "Copy link", Unpublished changes → "Update".
  • ⋮ menu (shadow-menu, radius-lg): Open · Open source chat · Share · Copy link · Rename · Archive.

Empty and edge states

  • No assets: centred greeting-style line "Assets you create in chats show up here", with a secondary "New chat" button.
  • No results: "No assets match "…"" and a Clear filters link in brand-ink.
  • Source chat deleted: provenance reads "Source chat deleted" in ink-muted, no link.
